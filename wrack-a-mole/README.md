# 🎯 Whac-A-Mole Game

A simple Whac-A-Mole style game built with [Godot](https://godotengine.org/) (or replace with your engine/framework).  
The goal is to hit the moles when they pop up before they disappear!

---

## 🕹 Features
- Random mole spawning
- Increasing difficulty over time
- Score tracking
- Game over screen
- Sound effects and animations (optional)

---
